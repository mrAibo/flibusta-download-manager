# Flibusta Download Manager

Userscript для Tampermonkey: пакетная загрузка книг с Флибусты. Добавляет на страницы сайта панель, которая собирает книги в очередь и скачивает их в выбранную папку, с повторами, паузой и продолжением после перезапуска браузера.

Текущая версия — **2.5.6** (имя файла остаётся `Flibusta_Download_Manager_2.5.0.user.js`, версия видна в заголовке скрипта и на панели). Что менялось — в [`CHANGELOG.md`](CHANGELOG.md).

## Что умеет

- **Страницы автора и серии** — флажки у книг, «Отметить все», скачивание отмеченных или всех книг, при желании со всех страниц каталога (до 30).
- **Страница одной книги** (`/b/<номер>`) — кнопка «Скачать (1)».
- **Рейтинги** «Топ дня», «Топ недели», «Популярные книги», «Оценённые книги» — у каждой книги флажок, «⬇» (скачать одним кликом), «+ автор» и «+ серия» (раскрыть книги автора или серии прямо под строкой). Раскрытые списки хранятся сутки.
- **Папка** — запоминается (File System Access API); без неё файлы идут в обычные «Загрузки».
- **Нестабильная сеть** — повторы с паузой, учёт `Retry-After` при 429/503, обрыв молчащего соединения через заданное время («Обрыв без данных», по умолчанию 20 с), упавшая страница каталога пробуется ещё раз в конце, а следующие за ней страницы ищутся по номеру; очередь сохраняется и продолжается после перезапуска.
- **История** — уже скачанные книги отмечены на странице зелёной «✓» и пропускаются (отключается настройкой).
- **Удобство** — панель сворачивается в строку со счётчиком (состояние запоминается), во время загрузки видно «Осталось ≈ …», по окончании очереди приходит уведомление. В раскрытом списке автора или серии есть «отметить все».
- **Безопасность** — адреса перенаправлений проверяются (никаких внутренних адресов, `localhost`, частных сетей), имена файлов очищаются от путей и зарезервированных имён Windows, текст сайта выводится только как текст.

## Установка

1. Установите расширение [Tampermonkey](https://www.tampermonkey.net/).
2. Откройте `Flibusta_Download_Manager_2.5.0.user.js` и установите его в Tampermonkey (или создайте новый скрипт и вставьте содержимое).
3. Откройте страницу автора, серии, книги или рейтинга на `flibusta.is` — сверху появится панель.

При первом скачивании Tampermonkey может спросить разрешение на обращение к файловому серверу сайта — разрешите.

Работает также с адресами Флибусты в Tor (`.onion`) и I2P (`.b32.i2p`).
